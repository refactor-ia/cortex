# Reasoning

Optional reasoning methods, adapter-driven deliberation, maintainer assessment
and advisory delivery guidance. Select by intent, not a mandatory pipeline:

- Issue/PR intake, duplicates, versions or feature pool: `cortex-maintainer-triage`.
- Direct PR/diff solution assessment: `cortex-maintainer-review`.
- Coordinating accepted work toward merge: `cortex-maintainer-delivery`.

Consult another capability only for named missing facts and return to the caller;
never restart its workflow recursively. Review owns technical criteria and the
shared Integration Contract for evidence-linked handoffs and freshness.
Triage owns report disposition and human feature decisions; technical success
cannot discharge missing acceptance or required proof. Only triage may apply
labels/comments within explicit user authorization and repository policy.
Skill selection grants no permissions; denied actions cannot be rerouted.
Review and delivery are advisory, execute and gate nothing, and never override
host consent or grant close, formal approval, code publication, merge or release
permission. No event listener is installed by these skills.
