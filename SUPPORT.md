# Support

## Choose the right channel

| Need | Where to go |
| --- | --- |
| Bug, scoped improvement, or documentation problem | Use the [repository issue forms](https://github.com/refactor-ia/cortex/issues/new/choose). |
| Security vulnerability | Report privately to [security@refactoria.dev](mailto:security@refactoria.dev) or use [GitHub Private Vulnerability Reporting](https://github.com/refactor-ia/cortex/security/advisories/new). |
| Code of Conduct incident | Report confidentially to [conduct@refactoria.dev](mailto:conduct@refactoria.dev). |
| General question | Use GitHub Discussions only if this repository enables and links Discussions. |

Community support is distinct from security and conduct reporting. Do not report vulnerabilities through public issues or conduct incidents through public community channels.

## Support expectations

Cortex provides community support without a support SLA, guaranteed private consulting, or a response-time promise. This repository is a target-architecture and community foundation, not a claim of completed implementation or supported releases. See [SECURITY.md](SECURITY.md) for private vulnerability reporting and [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) for conduct reporting.
