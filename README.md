# Cortex

Cortex is RefactorIA's clean, open-source foundation for a curated distribution of agent capabilities. Its canonical repository is [github.com/refactor-ia/cortex](https://github.com/refactor-ia/cortex).

> **Status:** This clean repository contains the target architecture and community foundation. Implementation is not complete, and this repository makes no installation, runtime-parity, or release claim.

## Start here

1. Read the [architecture overview](docs/architecture/overview.md) for the target product boundary.
2. Use the [documentation map](docs/README.md) to locate repository authorities.
3. Read [CONTRIBUTING.md](CONTRIBUTING.md) before opening an issue or pull request.

## Product boundary

Cortex is one curated distribution, not a collection of separately released or user-selected packs. It is designed to project approved capabilities into supported runtimes while preserving explicit user configuration ownership.

Cortex does not own Git or GitHub authority, lifecycle governance, SDD, TDD, review authority, or memory-server operations. `cortex-brains` remains a separate product for memory servers, storage, and backups.
